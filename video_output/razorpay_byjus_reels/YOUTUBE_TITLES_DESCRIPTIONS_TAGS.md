## Tips
- **Upload:** set the vertical thumbnail (`thumbnails/Thumbnail_*_1080x1920.jpg`) as the Shorts cover frame. Use the 1280×720 version if you also post these as regular videos or in a community post.
- **Pinned comment:** pin the "💬" question from the description to drive comments.
- **Instagram Reels:** use the first title as the caption hook, then the "In this short" bullets and 5–8 hashtags. Keep the photo credits.
- **Link the pair:** post them a day apart and reply to comments on one with the other. Both are Indian startup stories, so they cross-sell well.
